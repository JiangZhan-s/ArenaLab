# 分步任务

## T1：固定步长与输入序列

实现：实现20Hz逻辑、10Hz快照；每步最多消费一个合法输入。手动时钟检查边界、重复、倒序、巨幅位移。动作只推进内存，不写SQL。

验证与学习：预测输入重发两次的位移；查看 seq 和 last_processed_seq 的代码路径。

开始前由学习者写预测；完成后交付代码路径、反例、原始输出。

## T2：可见的客户端校正

实现：两个浏览器实时移动；本地预测、权威快照校正后重放未确认输入，远端插值。展示RTT、tick、误差与缓冲深度。

验证与学习：人为延迟100ms并停下操作，最终误差收敛；解释为何不能重复应用已确认输入。

开始前由学习者写预测；完成后交付代码路径、反例、原始输出。

## T3：有界资源与停顿策略

实现：慢读不能拖住tick；输入队列128、广播队列64。停顿最多追赶3tick，暴露调度落后。比较全快照与delta成本。

验证与学习：记录队列峰值、tick耗时/落后、网络字节；故意删去上限应被压力实验发现。

开始前由学习者写预测；完成后交付代码路径、反例、原始输出。
