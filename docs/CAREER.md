# 项目动机与面试定位
真实场景：低频双人竞技中的身份、匹配、裁决、断线恢复和公平结算。小团队可以选择现成平台；本项目作为学习实践用于理解并验证其中的关键机制。
适配：休闲游戏后台、FPS/MOBA在线后台、独立DS服务接入；Lab12提供有限的实时移动与客户端校正实验。不覆盖FPS物理同步、命中回溯、完整AOI或UE引擎开发。详细边界见 ROLE_FIT.md，面试证据见 MEASUREMENT_AND_INTERVIEW.md。
面试叙事：做过数据库与分布式课程 → 选择完整玩家旅程 → 定义故障下的承诺 → 对比方案 → 保存证据。
不得虚构公司委托、真实用户量。用bot提供负载，写明机器和命令分布。
证据专题：房间并发/慢连接；行动ACK/恢复；匹配唯一占用/幂等结算。
