# ADR 0003：连接票据一次消费与真实邮箱压力

参考实现复查发现两处测试盲区：同一session token曾可无限开新WS连接；同步reader等待action结果，使单连接无法真正填满房间mailbox。

改为登录提升epoch并签发一次WS接入资格，升级时在player行锁下原子消费。重连重新登录；旧连接保留时只能收到stale_session拒绝。浏览器用WebSocket子协议传短期票据，不放URL。

reader对action使用最多64个在途等待，房间mailbox仍64；超过预算返回overloaded。压力驱动用一个真实合法连接并发发送160条命令，不通过重复连接票据绕过会话语义。

这是加强原承诺，不放宽固定验收。慢读客户端单独登录，使旧连接失效；健康房间使用不同玩家。新增票据重用回归测试。
