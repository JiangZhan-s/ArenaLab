# ADR 0004：过期检查与演示持久化

准备超时和 owner 的 abort 分支必须在事务中释放 occupancy，不产生积分。Ready 与清理器通过同一 match 行锁串行化。

DS 结果事务在首次接受结果时检查实例心跳租约；已经持久化的同内容重放仍然幂等成功。不能依赖后台 Expire 的调度时机来决定过期结果是否合法。

演示 MySQL 使用 named volume；验证 MySQL 保留 tmpfs，测试数据是可丢弃的独立命名空间。停止演示不清除积分。部署并不提供生产备份、HA 或密钥管理。

固定验收未删改；新增回归覆盖准备超时占用释放和未运行清理器时的 DS 过期结果拒绝。
